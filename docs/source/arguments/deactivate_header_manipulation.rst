.. py:attribute:: deactivate_windows_header_manipulation
   :type: bool
   :value: False

   If set to ``True`` and the OS is Windows,
   the window title bar won't change color based on the :doc:`/concepts/AppearanceMode`.


.. py:attribute:: deactivate_macos_header_manipulation
   :type: bool
   :value: False

   If set to ``True`` and the OS is macOS,
   the window title bar won't change color based on the :doc:`/concepts/AppearanceMode`.
