.. py:attribute:: font
   :type: CTkFont | CTkFontArgs | tuple | str

   Font to be used for the displayed text.

   It can be a:

   - instance of :doc:`/utilities/CTkFont`;
   - dictionary containing valid :ref:`CTkFont arguments <font_arguments>`;
   - tuple with a length between 2 and 6 (:tkdoc:`Tkinter-style <fonts>`);
   - string representing a custom theme key.
