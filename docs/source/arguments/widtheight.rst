.. py:attribute:: width
   :type: int

   Width of the widget in |unscaled pixels|.

   If the geometry manager used to display the widget has been configured to stretch it, this value is ignored.


.. py:attribute:: height
   :type: int

   Height of the widget in |unscaled pixels|.

   If the geometry manager used to display the widget has been configured to stretch it, this value is ignored.
