Contributing
============

Feel free to open new `Issues`_ on GitHub for bugs or improvement requests.

If you have developed an improvement yourself, open a `Pull Request`_, but
please follow these simple rules:

- 1 feature |lr_arrow| 1 PR:
   Don't combine different changes into a single Pull Request.

   Maybe not all of them are needed, so we can only choose whether to merge all or nothing.

- Do not leave commented code:
   If you need to remove an entire section, just delete it.

- Do not add comments that refer to how the code was:
   "changed", "fixed", "it wasn't present" do not provide useful info and must be avoided.

- Try copying the coding style:
   We all have different quirks when we write code; try to match the style of the existing code.

   For example, use ``""`` for literal strings and add type hints for public elements.

- Update the documentation:
   If you add a new feature, document it properly in the ``docs`` folder.

- Log the change:
   Report what has been added, changed, or deleted in ``Changelog.rst``.
